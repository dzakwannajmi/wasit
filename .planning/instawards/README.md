# Instawards planning

This folder tracks Wasit's progress against the Instaward SOW specifically —
deliverables, evidence, and outreach traction. It exists separately from the
root `README.md` on purpose: the root README is written for a developer
deciding whether to use Wasit, while this folder is written for the Stellar
Chapter Lead / SCF reviewer checking the SOW against what was actually built.
Mixing the two would force one document to serve two different readers.

Two files here:

`checklist.md` maps every deliverable and evidence item in the SOW to its
current status — present, partial, or missing — with a one-line reason for
each, updated as work lands. `traction.md` is the outreach log: which teams
were contacted to self-test Wasit, when, and what happened, kept here so it
can be pasted straight into the next SOW's traction section without having to
reconstruct it from GitHub issue history.

Nothing here is meant to be polished prose. It's a working checklist, updated
in place rather than rewritten, so status can be trusted at a glance.
